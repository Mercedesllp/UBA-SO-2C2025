# Chapter 16 - Security

Security is a measure of confidence that the integrity of a system and its data will be preserved.
Protection is the set of mechanisms that control the access of processes and users to the resources defined by a computer system.

- Breach of confidentiality: Unauthorized reading of data.
- Breach of integrity: Unauthorized modification of data.
- Breach of availability: Unauthorized destruction of data.
- Theft of service: Unauthorized use of resources.
- Denial of service (DOS): Preventing legitimate use of the system.

Methods of attack:
- Masquerading
- Reply attack
- Man-in-the-middle
- Session hijacking
- Privilage escalation

To protect a system, we must take security measures at four levels:

- Physical
- Network
- Operating system
- Application

Remote Access Tool (RAT): Provides informationor allows easy access even if the originalexploit is blocked.

Common methods by which programs cause security breaches:

- Malware: Software designed to exploit, disable or damage computer systems. Trojan horse, spyware, ramsomware (encrypts info), trap doors.
- Code Injection: Executable code is added or modified.
- Viruses and Worms: A virus is a fragment of a code embedded in a legitimate program. Worms use a network to replicate and viruses depend on human activity. Some categories for viruses are:
  - File
  - Boot
  - Macro
  - Rootkit
  - Source code
  - Polymorphic
  - Encrypted
  - Stealth
  - Multipartite
  - Armored
