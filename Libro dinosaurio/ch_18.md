# Chapter 18 - Virtual Machines

host: Underlying hardware system that run the virtual machine.

Virtual machine manager (VMM or Hipervisor): Creates and runs VMs by providing an interface that is identical to the host.

guest: Process provided with a virtual copy of the host.

There are different types of VMMs.

Implementations of VMMs:

- type 0 hypervisors / Hardware based solutions that provide VM creation and management via firmware.
- type 1 hypervisors / Operating-system-like software built to provide virtualization.
- General-purpose operating sysyems that provide standard functions as well as VMM functions.
- type 2 hypervisors / Applications that run on standard operating systems but provide VMM features to guest OS.
- Paravirtualization, a technique in which the guest OS is modified to work in cooperation with the VMM to optimize performance.
- Programming-enviroment virtualization, in which VMMs do not virtualize real hardware but innstead create an optimized virtual system.
- Emulators that allow applicatiuons written for one hardware enviroment to run on a very different hardware enviroment, such as a different type of CPU.
- Application containment, which is not virtualization-like features but rather provides virtualization-like features by segregating applications from the OS.

---

VCPU (Virtual CPU): Represents the state of the CPU as the guest machine believes it to be. The information on the VCPU is used to load the right context in a context switch.

Building blocks needed for efficient virtualization:

- Trap-and-execute
- Binary Translation
- Hardware Assistance

Nested Page Tables (NPTs) are used in VMs so it can manage memory.
